## 🥷 Projeto em destaque — Yōkai no Ki SGI

### 👉 [github.com/Adriano-jose-dev/yokai-no-ki-sgi](https://github.com/Adriano-jose-dev/yokai-no-ki-sgi)

Plataforma **full-stack** de gestão para um dojo de artes marciais. É o projeto
que melhor representa meu trabalho: não é um CRUD genérico, e sim a **modelagem
fiel de um domínio com regras de negócio não-triviais**.

**O que ele resolve:**
- 💰 **Cobrança por sessão de tatame** com franquias e regras por plano
- 🔒 **Trava automática de inadimplência** (com bypass por acordo e job agendado)
- 🥋 **Régua de progressão de faixa** (Gakusei / Bushi) com meses para o próximo exame
- 🗂️ **Soft delete** — histórico dos alunos sempre preservado

**Engenharia por trás:**
- Autenticação **JWT / OAuth2** com autorização por papéis
- **Migrations** com Alembic · **job diário** com APScheduler
- **35 testes** automatizados (Pytest)
- **Docker Compose** (sobe tudo com um comando) e **CI/CD** no GitHub Actions
- Arquitetura documentada com diagramas

`Angular 17` · `FastAPI` · `PostgreSQL` · `Docker` · `GitHub Actions`
